# 64 GiB 大检材工作台（2026-10-17）

## 使用与边界

双击仓库根目录的 `启动大检材界面.cmd`，或运行 `forensic-gui-large.ps1`。普通 `启动取证界面.cmd` 和 `config/default.toml` 继续使用原容量设置；本机普通配置目前为 10 GiB。

大检材入口读取当前 `config/default.toml`，只把 `limits.snapshot_bytes` 设置为 68,719,476,736 字节（64 GiB）。模型、工具路径、超时、内存、CPU、输出、解包限制、磁盘保留空间及工作目录均沿用当前配置。该上限约束案件检材副本总量，不能作为内存用量或自动解包容量理解。

入口在 `config/local-large-evidence-<SHA256>.toml` 生成按内容摘要命名的本机配置，并将其传给现有 GUI；子进程继续使用同一路径。配置直接放在 `config/` 下，保持知识目录解析正确。已有同名配置内容不符时拒绝启动；显式传入另一个 `--config` 时拒绝，定制配置使用原 `forensic-gui.ps1`。生成配置包含本机路径，已列入 Git 忽略规则。

已知约 48 GiB 检材在 64 GiB 容量范围内，仍必须有足够实际工作盘空间，并留出 `reserve_disk_bytes`。复制前总空间预检和逐文件增长/磁盘变化/哈希检查继续执行。没有添加直接分析原件、任意 Shell、自动分卷登记或加密容器解密能力。

分卷应先做完整性核对，再作为整套压缩包处理。已有解包结果可以复用。提高登记容量不会确认未知容器的格式，也不代表已经取得题目答案。
