# 工具结果最终模型归纳（2026-10-17）

自动模型模式原本会在工具之间读取结果，并以 `finish` 给出候选答案。本轮补齐达到工具次数上限、连续两次没有新增证据时的收尾：停止工具调查后，允许模型根据当前题目和已有证据预览进行一次只读最终归纳。输出仍是有证据编号、字段及原值的 claims，解释写入 interpretation，不能回答的部分列入 uncertainties。报告沿用答案前置布局。

最终归纳的生成 schema 仅允许 finish/null request，运行时也拒绝任何新工具请求。格式错误不追加重试；字段引用错误仍共用整个案件原有的一次引用纠正预算，规划预算不重置。最终归纳前和接受 finish 时仍核验完整性，来源变化拒绝答案。模型失败保留工具停止状态、原输出和明确警告；不伪造已完成归纳。新增独立 final-review 审计日志、analysis_runs.final_review 状态及起止时间；旧日志不覆盖。正常 finish 不再叠加一次模型调用；显式 `--no-model` 继续完全不调用模型。报告重新生成只做校验和排版，不触发新的模型分析。

工具原始输出完整保留在案件中，模型看到的是原有有省略标记的受限预览，不声称每行都已阅读或全部题目已解答。partial/采集截断、失败与未知统计继续保持原语义。现有严格来源/字段/类型/原值校验未放宽，模型的文字解释仍需人工核对。无新增依赖、Shell 或工具白名单扩展。
